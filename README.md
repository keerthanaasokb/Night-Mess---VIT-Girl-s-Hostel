# 🌙 Night Mess – VIT Girls' Hostel

## 1. Project Overview
Night Mess is a student-built website designed for students living in the VIT girls' hostel. It helps students check the food menu, view estimated queue times, place orders, and track their order status.

**Target Audience:** VIT students who want a quicker and more convenient night-mess experience.

## 2. Design
The website features a modern, night-themed aesthetic with neon colours, attractive food illustrations, and a clean, user-friendly layout. It is designed to work on both desktop and mobile screens.

## 3. Features and Functionality
- **Food Menu:** Browse food items, prices, ratings, and availability.
- **Order Placement:** Add items to a cart and place an order with a single token.
- **Order Tracking:** Track order progress from received to ready.
- **Queue Tracker:** View estimated waiting times and crowd levels.
- **Reviews and Ratings:** Rate food items and share reviews.
- **Notifications:** Receive simulated alerts about order status, queue changes, and stock availability.
- **Theme Switcher:** Switch between dark and light themes.

## 4. Technology Stack
- **HTML5:** Website structure.
- **CSS3:** Styling, animations, and responsive design.
- **JavaScript:** Interactive features, cart management, order tracking, and notifications.
- **Local Storage:** Saves theme preferences and reviews in the browser.

## 5. Responsiveness
CSS media queries ensure the website adapts to desktop and mobile screen sizes.

## 6. Setup Instructions
1. Clone or download this repository.
2. Open `Night-Mess.html` in a web browser.
3. Explore the menu, add items to the cart, and test the interactive features.

No additional installation is required.
